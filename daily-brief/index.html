daily-brief는 만든 사람 본인만 사용하는 개인 데일리 브리핑 도구입니다. 매일 아침 Gmail 받은편지함과 Google Calendar 일정을 읽기 전용으로 훑어, 마감·중요 메일·할 일을 한 페이지로 정리해 로컬 컴퓨터에 만들어 둡니다.

하는 일

  • Gmail 받은편지함의 최근 메일 제목·발신자·요약을 읽어 중요도별로 분류
  • Google Calendar의 예정 일정과 마감을 날짜순으로 정리
  • 결과를 사용자의 로컬 컴퓨터에 HTML 파일 하나로 생성

하지 않는 일

  • 메일을 보내거나, 수정·삭제·라벨링하지 않습니다 (읽기 전용 권한만 요청)
  • 캘린더 일정을 만들거나 수정하지 않습니다
  • 데이터를 외부 서버로 전송하거나 제3자와 공유하지 않습니다
  • 광고·분석·추적을 하지 않습니다
